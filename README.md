# 📝 To-Do List

Aplicação web de gerenciamento de tarefas desenvolvida com HTML, CSS e JavaScript.

## ✨ Funcionalidades

- Adicionar tarefas
- Marcar tarefas como concluídas
- Desmarcar tarefas
- Excluir tarefas
- Adicionar tarefas utilizando Enter
- Alteração do ícone da tarefa
- Feedback visual para tarefas concluídas

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- Material Symbols

## 🚀 Como executar

Clone o repositório e abra o arquivo `index.html` no navegador.

## 📚 Objetivo

Projeto desenvolvido para praticar manipulação do DOM, eventos, funções,
classes CSS e interação entre JavaScript e HTML.
